# Agent Note: 专用 Windows 凭据与加密读取管道

Status: implemented

[English](2026-09-10-windows-credential-bridge.md) | 中文

## 问题

固定凭据引用需要真正的操作系统读取器。把 Key 放进命令参数会增加命令和进程观察中的暴露路径。打印明文的原生读取器也会使凭据进入意外的诊断采集。

## 决策

[专用 Windows 组件](../../../../scripts/p0-b/windows-credentials/README.zh.md)使用四个固定的通用凭据管理器目标。交互式录入接受 SecureString，不接受值为 Key 的命令参数。可信读取器要求显式引用授权，并接入现有一次性租约，不发现全局账号或配置。

原生 stdout 只承载用父进程每次新建的 RSA-4096 公钥生成的 RSA-OAEP-SHA256 封装。加密由内置密码实现处理，Windows 负责落盘保护。凭据限制为 384 个可打印 ASCII 字节，超过限制拒绝而不是截断。通道具有显式程序／源码哈希、环境、时限和输出限制；失败丢弃原生诊断内容。

规划进程包装器在等待外部工作前复制可信调用输入，按 UTF-8 字节限制已脱敏的保留输出并覆盖 EOF，输入投递失败则取消。独立的终止宽限期限制继承管道的等待；宽限期后返回明确的未验证清理状态，不声称所有后代已经退出。心跳缺失或冻结不能证明退出。生命周期 fixture 在就绪前创建心跳，观察实际推进并使用 detached 存活后代；测试清理与包装器拥有的终止能力保持区分。

无密钥 Codex 启动配置生成器校验实际配置锁并生成固定原生 argv／配置。它不签发授权或读取凭据；原生强制行为与可信生产调用方仍是独立责任。

最小调用入口使用投影中的唯一参数集和显式 Windows 作业属主。CLI 本身经由哈希钉版的门控启动器启动：启动器 PID 先加入作业，之后才创建 CLI，因此 CLI 的首条代码已在作业内运行。提示词释放仍要求调用存活、未取消且指派得到确认；被拒绝或迟到的指派既不能释放输入，也不能启动 CLI。helper 协议拒绝超长或相互矛盾的回应。销毁要求获得确认并观察到正常关闭，失败在后续调用中继续保留。入口把未完成清理显式报告为阻塞，并在调用失败时保留清理事实。

入口独占创建全新的运行根目录，而不是仅依靠配置文件的独占创建。这不等于 Windows ACL 强制控制。直接在启动后按 PID 指派会让目标启动阶段处于作业之外，推迟 stdin 也不能阻止启动代码创建后代，因此由门控启动器在 CLI 首条代码运行前确立成员身份。终止后成员数为零，既不认证原子启动，也不认证完整进程树。

放行权绑定精确且存活的启动器，并在取消或属主失败时失效。尚未指派的启动器还不受任何作业包含，因此由属主显式停止；销毁既等待该启动器关闭，也等待 helper 确认并关闭。迟到的 go 标记不能恢复已经过期的等待。启动器原生失败测试与模拟协议控制保持区分。

入口要求完整的 `PlannerProcessOwnership` 适配器，并显式映射作业属主名称不同的门控方法。启动方法可选时，结构类型会接受未经适配的属主；强制完整适配并测试实际入口，避免仅凭 helper 测试认证并未使用的启动路径。

## 考虑过的替代方案

明文文件和命令行密码参数增加暴露路径。读取器 stdout 输出明文会使意外进程日志变得不安全。完整平台凭据服务及公网管理界面需要超出本支持组件的授权和部署约定，本组件不宣称已经交付它们。

字符串长度不能覆盖多字节输出；只检查数据回调会遗漏延迟的 EOF 输出。先保留超限片段再终止进程不能落实内存边界。只等待 stdio 关闭可能在直接子进程退出后卡住。有界方案明确放弃取消后的诊断内容和完整后代清理声明。

## 影响

安全边界是操作系统账号，不是凭据名称前缀或加密管道。共享该账号的产品 agent 仍需要有效的操作系统隔离。不自动激活模型，不确认 Key 轮换，不授权 HTTPS 或规划调用。[远端 r07 回执](../../../../development/remediation/2026-09-10/credential-store-r07/verification.json)区分合成协议测试与原生 Windows 验证；[本机 r08 回执](../../../../development/remediation/2026-09-10/credential-store-r08/verification.json)记录已执行的 Windows 原生结果、解析兼容修复和尚未完成的接入限制；[r10 回执](../../../../development/remediation/2026-09-10/planner-windows-r10/verification.json)保留原始 Windows 观察。[r11 更正](../../../../development/remediation/2026-09-10/planner-observer-r11/verification.json)记录缺失心跳缺陷，并限定相关生命周期结论；[r12 回执](../../../../development/remediation/2026-09-10/planner-entry-r12/verification.json)记录钉版 CLI 无密钥投影验证、专用作业对象的进程树实测和 PowerShell 标志缺陷。[r13 复核](../../../../development/remediation/2026-09-10/ownership-failure-r13/verification.json)记录失败状态控制及其明确模拟的操作系统边界；[r13 Windows 后继回执](../../../../development/remediation/2026-09-10/planner-gate-r13/verification.json)记录门控启动器原生运行、确定性延迟指派控制与补全的 PROCESS_INFORMATION 布局探针。
