# Agent Note: 所有者模型声明与 CLI 升级分离

Status: implemented

[English](2026-09-09-owner-model-config-lock.md) | 中文

## Problem

CLI 安装默认值与平台模型策略的责任方不同。依据新 CLI 版本重建模型选择可能静默改变路由或思考等级。脱敏后的凭据文字不是可复用的认证值。

## Decision

[配置参考](../../../../config/agents/README.zh.md)管理四种产品 harness 的单一版本化非密钥声明。固定凭据引用指向外部秘密，不保存原值或秘密派生摘要。离线检查器验证非密钥字段及锁，并拒绝只升级 CLI 的提案改变配置；报告从不认证原生执行或凭据已导入。

所有者指定值原样保留，即使原生兼容性尚未核验；不支持的设置不会被改写。内置 OpenCode 路由不捏造地址覆盖。产品默认配置不改变另行指定的开发规划者及硬审核者。

## Alternatives considered

内联 Key、可恢复混淆及与密文同置的解密材料会随源码暴露认证材料。读取全局 harness 设置违反凭据隔离边界。升级时自动重新生成锁，会放行比较器本来要识别的配置漂移。

## Consequences

声明可跨 CLI 版本保留，比较结果确定。锁不是签名或授权服务，必须与可信基线比较。运行时适配器接入、安全凭据导入、实际配置观察及原生兼容性仍是独立必需集成。排版规范化的模型摘要不重新定义历史候选的原始字节摘要。

## Verification

离线专项测试覆盖指定值原样保留、仅凭据引用、危险 URL、策略放宽、锁不匹配、升级提案变更、命令行错误脱敏及未激活报告。检查不使用真实 Key 或模型接口，也不替代受支持引擎测试或独立节点审核。
