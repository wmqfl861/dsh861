# Agent Note：离线审计控制与生成式交接

状态：已实现

[English](2026-09-09-audit-controls-and-handoff.md) | 中文

## 问题

P0-B 的 adapterless foundation 曾可能返回退出码零并删除证据，同时记录仍显示目录保留。旧 schema 允许在没有产品行为观察的情况下填写顶层 PASS。独立维护的交接文字与节点状态发生漂移，候选摘要也没有明确其字节口径。

## 决策

用户授权进行审查整改维护。严格参数解析、BLOCKED 非零退出、证据保留、后继 foundation schema 覆盖约束，以及独立语义和原始字节检查现在覆盖这些局部合同。覆盖约束不替换历史 schema，也不实现计划中的产品 evidence v2 runner。AC 标题从完整产品规格核对；测试语义仍需审核。

交接页由当前节点选择文件和已有节点状态生成，生成过程不写批准状态。历史批准仅对应固定候选，不覆盖后续提交。P0-B 范围纠正是修订请求，不是伪造指定 Codex CLI 的计划。在所需真实计划、证据与独立审核完成前，P0-C 保持关闭。

## 考虑过的替代方案

重写历史计划或将不匹配的候选字节归一化，会抹去已审核工作树字节与 Git 归档字节的区别，因此这些记录保持不变。foundation 检查与真实产品验收分开；结构合法的文件不能证明供应商身份、外部副作用或凭据轮换事件。

## 影响

离线控制可在不调用模型的条件下复现。仓库集成检查和真实平台验证仍然必需。运行时 stderr 脱敏、凭据轮换核实和真实 adapter 仍待处理。本 Note 记录已实现的维护控制，不表示节点完成或调用了外部规划者、审核者。
