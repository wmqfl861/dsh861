# 本地派发与独立审核模板

类型：可复制执行模板。尖括号在真正派发时用已有证据填写，不把模板文本原样当实际命令执行。

## 实施子代理

```text
你负责 B01-<任务ID>，总控是唯一整合与Git写入者。

先读：delivery-plan/README、SCOPE_AND_AUTHORITY、EXECUTION_PROTOCOL，
再读 WORK_PACKAGES 中本任务完整卡和正式计划对应章节。
实际计划包路径由总控提供，不假定它已合并到主工作树。

输入candidate/commit：<完整SHA或manifest>
已完成前置：<任务ID、审核、证据>
允许读取：<相关来源>
唯一允许修改/新增：<完整路径白名单>
禁止修改：<共享文件、其他工作包、受保护面>
临时目录/端口/home：<本任务自有资源>
资源锁：<是否需要heavy-build或生成器；持有前不得执行>
预期交付：<实际文件、行为、产物、证据路径>
必需验证：<真实命令与环境；需要真实平台的项目>
拒绝路径/负控：<具体目标失败；恢复规则>

先复现或保留真实首失，再实现最小改动。
在范围内自行修复，不因每个普通失败回用户索要指令。
需要改清单外文件时向总控给出准确必要性；不得自行扩大。
不修改用户全局环境、凭据、其他项目或历史证据。

不得自己push/merge/rebase/reset/stash/clean，不运行全仓生成器覆盖他人。
工作结束先自检，保存manifest和真实exit，将固定文件交CP1。
报告 DONE_FOR_REVIEW / BLOCKED_DEPENDENCY / NEEDS_SCOPE，
不能以退出码0、模拟结果或缺失原件冒充真实验收。
中断前保存实际已做工作和运行资源，恢复者不能重复启动仍活跃任务。
```

## 独立子代理审核

```text
你是 B01-<任务ID> 的独立复核者，不是这批文件的实现者。
只审固定candidate <hash>，不修改源码、预期、原始证据或任务标准。
本次检查属于CP1/CP2，不得自称指定Codex/OpenCode，除非确实通过规定CLI调用。

输入：正式计划片段、任务卡、白名单、完整diff/新增文件、测试与负控、
工具/环境/exit、资源清理记录、NOT_RUN。
核查：问题是否真的复现；修复是否解决原因而非改断言；替身契约是否接近真实命令；
异常与异步资源是否释放；权限与数据边界是否保持；实际生成和双语事实是否一致；
最终文件是否和证据输入相同。

有条件PASS必须逐条列整改条件，不得在条件未满足时推进为accepted。
给出 PASS / CHANGES_REQUESTED / BLOCKED，
每个发现含目标文件、行为、复现或证据、阻断性及建议最小验证。
原命令无输出/超时/退出码缺失如实标记，不自行补推。
获准验证可执行但需先持有资源锁；不得调用未授权模型/网络服务。
```

## 总控整合复核

总控收到子代理结果后先核对路径所有权、基线和manifest，再取得CP1；不因口头PASS直接合并。每次波末登记所有已停止任务、未完成边、当前重型进程和共享产物身份。Git只由总控操作，未知远端提交先保存现场报告。

模板是本阶段任务分配说明，不是本次已经有代理运行或已经审核通过的记录。
