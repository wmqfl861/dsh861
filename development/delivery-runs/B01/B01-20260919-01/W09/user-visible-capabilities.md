# W09 用户可见能力摘要（一页，如实）

对象：dsh861 当前 HEAD `f5ab2fed` 的已交付底座能力。这不是多智能体公司平台的能力清单；公司语义（项目/岗位/成员/铁律管理台/数据库/三端交付）尚未建设（见 [requirements-matrix.b01.md](requirements-matrix.b01.md)）。

## 现在真实可用的

- **dsh 本体**：以 profile 组合启动的 agent 终端（CLI/SDK），含 bash/pwsh（本地与沙箱三档）、文件读写与搜索、web 搜索/抓取、todo、计划模式、后台 job、会话持久化与恢复、会话标题、压缩、超时保护。
- **子代理委派**：模型可经 `subagent`/`subagent_fork` 工具派生进程内子代理并续接；安装可选 Bundle 后可把任务委派给真实 Codex 或真实 Claude Code 一次性会话（默认预设中对应工具行为 `disabled`，需安装+启用）；亦可配置任意 ACP 子进程后端。
- **权限与沙箱**：read-only / workspace-write / danger-full-access 三档进程沙箱（Windows 用 ACL 实现），无法强制时拒绝执行；敏感操作一次性人工审批（无应答者即失败关闭）；权限以预设选择器呈现。
- **技能与外部工具**：本地/多源技能目录与按需加载；外部 MCP 服务器的工具可挂载为原生工具（`mcp__<server>__<tool>`）。
- **工作流编排**：模型可用 JS 脚本编排子代理扇出（workflow 工具），ralph 固定目标循环，实验性 agent-team（命名队友、持久消息与任务板，重启可恢复；单进程共享目录）。
- **Web/桌面界面**：浏览器经 `dsh web`、或 Electron 桌面壳（无监听端口、捆绑 Node/pnpm、单实例锁、独立 profile）使用会话/设置/模型/插件/审批/交付物等中文界面；桌面支持整包检查-下载-安装更新。
- **可追溯性**：模型可见输入均可从会话日志重建；会话格式相邻迁移（v0→v3）带拒绝路径，已发布记录不可覆盖。

## 明确不存在或不满足的（对规格而言）

- 四种 harness 只接入两种（无 OpenCode、无 Grok）；已接入两者的原生配置/登录仍走宿主用户全局状态（与隔离要求相反，属当前设计）。
- 无 PostgreSQL、无 GBrain 记忆、无知识权限；持久化为本地 JSONL/SQLite。
- 无公司控制台（项目/岗位/成员/铁律/看板）、无规则版本与冲突管理。
- 无设计/美工交付链，无网站/App/小程序参考业务交付。
- 无预算费用上限动作、无外部副作用幂等、无组件并行版本/回退、无备份恢复演练。
- 取消/资源回收、沙箱拒绝、崩溃恢复等在底座层有实现与测试，但未在四 harness 产品语境下验收。
